# ESM Vertretungsplan
## Public releases

This is the repo where the downloadable released files of the ESM Vertretungsplan app will be available.

## How to download/install
* **iOS and Android**: On the [App Store](https://apps.apple.com/de/app/esm-vertretungsplan/id6761420188) and [Google Play Store](https://play.google.com/store/apps/details?id=com.esmdeveloper.esmVertretungsplan)
    * Android - Other option: Download the AAB from the latest release and do your thing.
* **For Intel Macs**: You can download the DMG from the latest release
* **For Windows**: Contact us or open an issue (we don't have a Windows PC, so we cannot generate the MSI file...)
* **Any other platforms**: Not supported - not planned. But you can still open an issue and we will see what we can do.
